# スクリーンショット運用

ポートフォリオには、実際に動作確認した画面だけを使用します。サンプルは「年商600万円」の架空データに統一し、入力値を変更した場合も個人情報を含めません。

## 推奨ファイル

| ファイル | 推奨サイズ | 内容 |
| --- | --- | --- |
| desktop-overview.png | 1425 × 990 | 基本情報の入力、ステップ、右側のリアルタイム予測 |
| desktop-results.png | 1425 × 990 | 税・社会保険、手取り、主要指標、毎月の準備額、負担率 |
| desktop-scenarios.png | 1425 × 990 | 月別予測の末尾、4シナリオ比較、納税時期 |
| mobile-input.png | 375 × 812 | ステップ入力と下部の予想負担バー |
| mobile-results.png | 375 × 812 | スマートフォンの主要結果と税目別内訳 |

## 撮影手順

1. npm run build と npm run preview を実行する。
2. localStorageを削除し、年商600万円サンプルを選ぶ。
3. 2026年分、架空サンプル、概算であることが読める状態にする。
4. PCは1440px幅、モバイルは390px幅を基準に撮影する。
5. 結果画面では「年末までの予測」を選択する。
6. desktop-scenarios.pngでは、月別予測とシナリオ比較の見出し・数値が読める位置までスクロールする。
7. コンソールエラー、画像欠け、横スクロール、フォーカスの残像がないことを確認する。
8. PNGとしてこのディレクトリへ保存し、docs/MANUAL_QA.mdのチェック欄を更新する。

## 注意

- 実在の氏名、住所、屋号、取引先、売上明細を使わない
- ブラウザのタブ、ブックマーク、通知、ローカルパスなど不要な情報を写さない
- UIを画像編集で作り替えない
- 税額は架空サンプルの概算であることが分かる文脈と一緒に掲載する
- ファイル名を変更した場合は docs/portfolio.md と docs/PORTFOLIO_ADD_PROMPT.md も更新する
